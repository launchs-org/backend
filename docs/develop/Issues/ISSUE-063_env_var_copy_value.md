# ISSUE-063 環境変数・シークレット値のコピーボタン追加

## 親 Issue
なし

## 概要
`EnvVarSidebar`（`frontend/src/pages/ProjectDetailPage.tsx`）の各環境変数アイテムに値をクリップボードにコピーするボタンを追加する。
通常変数はワンクリックでコピー、シークレットは「表示」ボタンで値を表示している状態かどうかに関わらずコピーできるようにする。

### 背景
環境変数の値をアプリ内で確認・転用したいケースがあるが、現状は値を選択してコピーするしかなく、シークレットは `••••••••` 表示のためそもそも選択できない。

### 実装方針
- `navigator.clipboard.writeText(value)` を使ってコピーする
- コピー完了後は一時的にボタンアイコンを `Check` に差し替えて視覚フィードバックを与える（1.5 秒後に `Copy` に戻す）
- シークレットの場合、値が空文字（バックエンドがマスクして返している可能性）なら「値が取得できません」等のメッセージを表示する
- `Copy` アイコンは `lucide-react` からすでにインポート済み（`ProjectDetailPage.tsx:14`）のため追加インポート不要

## 変更ファイル一覧

- `frontend/src/pages/ProjectDetailPage.tsx`（編集）
    - 何を: `EnvVarSidebar` 内の各環境変数アイテムの右端ボタン群に `Copy` ボタンを追加する。`copiedId` state（`string | null`）を追加し、コピー成功時に 1.5 秒間 `Check` アイコンを表示する。`handleCopy(envVar: EnvVar)` 関数を追加して `navigator.clipboard.writeText(envVar.value)` を呼ぶ
    - なぜ: シークレット含む環境変数の値をワンクリックでコピーできるようにするため
