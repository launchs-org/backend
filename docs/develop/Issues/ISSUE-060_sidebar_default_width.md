# ISSUE-060 サイドバーのデフォルト幅を拡大する

## 親 Issue
なし

## 概要
プロジェクト詳細ページのサイドバー（Deployment 詳細・作成フォームを表示する iframe パネル）のデフォルト幅を現在の 700px から拡大する。

### 背景
現在 `SIDEBAR_INITIAL_WIDTH = 700`（`frontend/src/lib/config.ts:8`）が設定されており、ユーザーからコンテンツが詰まって見にくいとフィードバックがあった。

## 変更ファイル一覧

- `frontend/src/lib/config.ts`（編集）
    - 何を: `SIDEBAR_INITIAL_WIDTH` を `700` から `900` に変更し、`SIDEBAR_MIN_WIDTH` も合わせて `900` に変更する
    - なぜ: サイドバー初期表示時のコンテンツ表示領域を広げ、フォームや詳細情報が見やすくなるため

## テスト確認項目

- [ ] プロジェクト詳細ページを開いたとき、サイドバーが 900px 幅で表示されること
- [ ] サイドバーのリサイズハンドルで幅を変更できること（最小幅も 900px になっていること）
- [ ] サイドバーを閉じて再度 Deployment を選択すると 900px 幅で開くこと
