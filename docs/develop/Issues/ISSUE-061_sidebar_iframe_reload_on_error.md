# ISSUE-061 サイドバー iframe のロード失敗検知と再読み込みボタンの追加

## 親 Issue
なし

## 概要
プロジェクト詳細ページのサイドバーに埋め込まれた iframe がロードに失敗した場合に、スピナーが無限に回り続ける問題を修正する。
ロード失敗を検知してエラー表示と再読み込みボタンを表示する。

### 現在の挙動
`iframeLoaded` フラグが `false` のままスピナーが表示され続ける。iframe の `onError` イベントや `onLoad` でのステータスコード検知がないため、ロード失敗時にフォールバック UI が表示されない。

### 対応方針
1. `iframeError` state を追加し、ロード失敗時に `true` にセットする
2. iframe の `onLoad` イベントで `contentDocument` が取得できない（クロスオリジン制限）または `src` が空の場合に備え、タイムアウト（例: 10 秒）でローディングが終わらない場合はエラー扱いにする
3. エラー状態では「読み込みに失敗しました」メッセージと「再読み込み」ボタンを表示する
4. 再読み込みボタン押下で `iframeError = false`、`iframeLoaded = false` にリセットして iframe の `src` を再セットする（key を変えて強制再マウント）

## 変更ファイル一覧

- `frontend/src/pages/ProjectDetailPage.tsx`（編集）
    - 何を: `iframeError` state と `iframeLoadTimeout` ref を追加する。iframe の `onLoad` に 10 秒タイムアウト検知ロジックを追加する。エラー状態のフォールバック UI（エラーメッセージ＋再読み込みボタン）を iframe 上に重ねて表示する。再読み込みボタンで state をリセットして iframe を再マウントする
    - なぜ: ロード失敗時にスピナーが永遠に回り続けるユーザー体験を改善するため

## テスト確認項目

- [ ] iframe が正常にロードされたときはスピナーが消えてコンテンツが表示されること
- [ ] iframe のロードが 10 秒以上かかる（または失敗する）場合にエラーメッセージと再読み込みボタンが表示されること
- [ ] 再読み込みボタンを押すと iframe が再ロードされること
- [ ] 別の Deployment を選択したときに iframeError がリセットされること
